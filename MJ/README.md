# Meide Android 테스트 앱

[**Meide AAB 다운로드 · 버전 코드 5 (약 93.6MB)**](https://github.com/SMWUmeide/meide/raw/refs/heads/App/MJ/Meide-0.1.0-5.aab)

현재 구현된 화면과 기능을 담은 Google Play 테스트 제출용 Android App Bundle입니다.
AAB 파일은 휴대폰에 직접 설치하는 파일이 아닙니다. Google Play Console의 테스트 버전에 업로드한 뒤 테스터에게 설치 링크를 배포하세요.

AAB 구조와 업로드 서명, 16KB 메모리 정렬 검사를 통과했습니다. 실제 휴대폰의 카메라·GPS·QR 동작 검증은 별도로 필요합니다.
첫 Play 업로드 후 Google의 앱 서명 인증서를 지도 설정에 추가하고, 새 기기의 프로필을 테스터 명단에 등록해야 제한된 메뉴 분석·주변 식당 API를 사용할 수 있습니다.

버전 5에는 동반인 목록의 원형 `+` 버튼을 적용했습니다. 누르면 ‘이번 여행 동반인’ 카드에 추가되고 목록에는 ‘함께하는 중’으로 표시됩니다. ‘빼기’를 누르면 다시 `+`로 돌아오며 친구 연결은 유지합니다. 실제 친구 화면과 과일 사진 연결 예시에 함께 적용했습니다.

식당을 확인하면 공식 웹사이트의 메뉴를 먼저 읽고 한국어로 번역합니다. 웹 메뉴가 없거나 접근/읽기에 실패하면 촬영한 메뉴판의 글자로 자동 진행합니다. HTML, PDF, 메뉴 이미지를 지원하고, 가져온 웹 메뉴의 원본 링크를 표시합니다. PDF 앞 2쪽·최대 5,000자를 처리하며 일부만 가져온 경우 안내합니다. 모든 식당 사이트나 지점별 메뉴를 지원하는 것은 아닙니다.

기존 하루 2회·전체 600회 제한을 유지합니다. 이전 전체 자동 검사 85개 통과 후 이번 변경 관련 검사 4개와 타입/린트 검사를 다시 통과했습니다. 브라우저에서 `+`로 추가하고 ‘빼기’로 되돌리는 동작도 확인했습니다. 한국식 AI 음식 설명과 준비 중인 주문·마이페이지 기능은 포함되지 않습니다. 서버에는 새 화면을 배포했지만 Google Play 제출·실기기 검증은 별도입니다.

이전 버전 코드 3·4 파일도 같은 폴더에 보관했습니다. 웹 메뉴 처리 기능은 버전 코드 4부터, 원형 동반인 추가 버튼은 버전 코드 5부터 포함됩니다.
