# 한국인을 위한 음식 해석 · 2026-10-17

- 디자인 기준: https://www.figma.com/design/71kRa7h4lu9GfFMRXLKFXk?node-id=2-23318
- 메뉴·상세 기준: 2:15783, 2:15829, 2:15850, 2:17463. 원문 → 쉬운 이름 → 설명 → 사진·수량 구조, 상세의 사진·설명·조리법·출처·수량을 유지.
- 메뉴 목록의 별도 ‘자세히 보기’ 링크를 제거하고 카드 선택으로 상세 진입. 한식 비교 요약을 추가.
- 공식 사실: lib/menus/solita-zuppa.json 및 solita-zuppa-review.json의 기존 출처·원문·가격·재료·조리법을 보존.
- 편집 비교: public/korean-dining.js. 한식과 닮은 점 및 다른 점을 별도 패널로 표시하며 공식 번역으로 표시하지 않음.
- 테스트 메뉴의 음식 16개 전부에 비교를 추가. 와인 14개에는 한식 비교를 강제로 붙이지 않음. 전체 공식 메뉴의 일부 음식과 정확히 일치하는 일반 음식명에도 추가 적용.
- 알 수 없는 이름·변형 메뉴는 원문과 기존 설명 유지. 가격·수량·ID·원어 주문명은 변경하지 않음.
- 비교는 맛을 예상하는 편집적 설명이며 식당의 조리법을 새로 확인한 정보가 아님. 양·매운 정도·재료 제거 가능 여부를 추정하지 않음.
- 현재 사이트는 기존 사용성 테스트 모드 유지: 실제 사진 AI 분석이나 자유 요청 자동 번역이 새로 연결된 것은 아님.
