# 최신 프로토타입 인수인계

2026-10-17 공개 버전 25를 반영했습니다. 이전 2026-10-11 화면 안내를 최신 내용으로 교체했습니다.

- 시작·실행·파일 구성: [README](README.md)
- 두 사람 시점과 쉬운 실행 방법: [MJ 전체 안내](../README.md)
- 직접 실행할 수 있는 Node.js 버전: [gourmet-app](../gourmet-app/)

공통 프런트엔드에 박성호·김미영 시점, 각자 수량·공유 장바구니, 최신 한국어 메뉴 해석, 한 줄 요약, 요청사항 번역·마주보기 대화, 주문 확대 화면이 포함됩니다. 별도의 두 코드베이스를 편집할 필요가 없습니다.

현재 디자인은 Pretendard·흰 배경·벽돌색 포인트·하단 글래스이며, 스타벅스 스타일 시안은 되돌린 상태입니다. 주문 확대 화면 상단 배치, 벽돌색 확대 아이콘의 오른쪽 정렬 및 마지막 위치 조정(12px), 요청사항 번역과 대화 시작 아래 안내 문구 제거까지 들어 있습니다.

촬영 흐름은 실제 OCR 대신 공식 고정 메뉴를 쓰는 사용성 테스트입니다. 번역은 외부 연결을 사용하며 식당에 주문을 전송하지 않습니다. 최신 실행·검증·제약은 연결된 README를 기준으로 합니다.
