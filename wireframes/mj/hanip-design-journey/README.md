# 한입 · 유럽 미식 가이드 디자인 프로토타입

2026-10-27까지 개선한 최신 화면과 상호작용을 담은 버전입니다. 기존 7주차의 실제 API·두 사람 장바구니 검증 버전은 형제 폴더에 그대로 보존했습니다.

**[공개 프로토타입 열기](https://hanip-design-journey.alswn2963.chatgpt.site/)** — 로그인 없이 접속할 수 있습니다.

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치나 API 키 없이 실행합니다.

```sh
cd wireframes/mj/hanip-design-journey
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 다른 포트는 `PORT=4174 npm start`로 지정합니다. `index.html`을 직접 열면 모듈과 검색용 Worker가 작동하지 않으므로 HTTP 서버를 사용해야 합니다.

## 이번 버전의 목적

갤럭시 S26의 1080 × 2340 비율을 기준으로 데스크톱에는 360 × 780 CSS px 기기 프레임을, 모바일에는 반응형 화면을 제공합니다. 메뉴판 촬영부터 식당 확인, 음식 이해, 함께 메뉴 선택, 주문, 마주보기 대화, 영수증과 평가까지 디자인 흐름을 검토합니다.

## 화면과 상호작용

- 홈: 국가·도시 캡슐, 겹친 공유 인원 아바타, 촬영·최근 메뉴·미평가·주변 식당 진입, 가로형 입맛 랭킹, 글래스 하단 탭.
- 여행지: 한국어·영어 검색, 국가 필터, 국기와 현재 여행지 표시, 선택·저장·변경.
- 촬영: 여러 장을 찍어도 동일한 미리보기 영역 유지, 장수·사진 묶음, 확인·확대·삭제·추가 촬영, 로컬 앨범 가져오기.
- 분석·식당 확인: 단계별 분석 시연, 지도와 위로 올리는 패널, 구글맵의 실제 식당 대표 사진, 간결한 식당 선택.
- 메뉴: 수프 4개·메인 요리 12개·칵테일 6개. 텍스트·밑줄 카테고리, 2열 사진 카드, 원문·한국식 설명·현지 및 원화 가격, 버섯·가지 주의 표시.
- 상세: 한국 음식에 빗댄 설명, 식당 웹메뉴에서 확인한 정보, AI의 보충·추정 정보를 분리.
- 함께 고르기: 동반인 담기 시연, 2초 알림과 지속되는 선택자·수량 표시.
- 장바구니·주문: 사람별 수량·삭제, 선택 팁과 합계, 하단 고정 금액, 한국어·이탈리아어 주문, 음성·확대, 지원하는 예시 요청의 문장 반영.
- 대화: 시작 전 주문 문장 표시 확인, 직원 쪽 180도 회전, 5초 뒤 예시 대화, 발화자 기준 좌우 정렬, 현재 발화 영역 그라데이션, 중앙 종료 버튼.
- 식사 후: 영수증 요약·현지 결제 문화·추가 요금 계산, 주문내역, 3단계 평가, 별점·리뷰 수·한 줄 평을 제공하는 랭킹.
- 동반인·마이페이지: 친구 관리, 내 입맛, 프로필과 설정.

## 실제 구현과 시연의 구분

| 구분 | 현재 동작 |
| --- | --- |
| 도시 검색 | 실제 검색. 유럽 58개 국가·지역, 1,022,909개 GeoNames 지명. 빠른 검색 후 전체 데이터 결과를 갱신하며, 한국어 명칭·별칭 및 근사 발음을 지원합니다. |
| 도시·장바구니·평가·취향 저장 | 현재 브라우저의 로컬 저장소에 실제 저장합니다. |
| 사진 가져오기 | 로컬 파일을 읽어 미리보기만 제공합니다. 서버에 업로드하지 않습니다. |
| OCR·자동 식당 판별·근처 식당 | 지정한 식당과 예시 데이터를 이용한 화면 시연입니다. |
| 공동 장바구니 | 현재 버전은 동반인 추가 상황의 시연입니다. 서로 다른 기기의 서버 동기화가 아닙니다. |
| 번역·통역 | 준비된 문장과 제한된 요청 패턴의 시연입니다. 범용 AI 번역·실시간 음성 인식은 연결하지 않았습니다. |
| 주문 음성 | 브라우저의 음성 합성을 사용하며 기기의 지원 여부에 따라 달라집니다. |
| 환율 | €1 = 1,550원의 시연 환율입니다. 실시간 시세가 아닙니다. |
| 랭킹 | 초기 평점·리뷰는 시연 데이터입니다. 내 평가는 5·3·1점으로 환산해 이 기기의 평균에 반영합니다. |
| 권한·로그인 | 설정 상태와 로그인 문구는 디자인 시연이며, 실제 계정 인증이나 OS 권한 변경이 아닙니다. |

기존 버전에서 검증한 API 기능이 이 디자인 버전에 모두 이식되었다는 의미는 아닙니다. API 키·유료 호출·실제 주문 전송 없이 화면을 반복 검토하기 위한 별도 결과물입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 화면 진입점과 데스크톱 프리뷰 프레임 |
| `dist/app.js` | 전체 화면·상태 전환·상호작용 |
| `dist/style.css` | 그라데이션·타이포그래피·반응형·글래스 탭 |
| `dist/menu.json`, `dist/korean-dining.js` | 공식 메뉴 스냅샷과 한국식 해석 |
| `dist/city-worker.js`, `dist/cities.json`, `dist/cities/` | 실제 도시 검색과 지명 데이터 |
| `dist/destinations.js`, `dist/korean-place.js` | 국가·별칭·근사 발음 처리 |
| `dist/assets/` | 실제 메뉴 사진·식당 사진·사진 출처 |
| `SOURCE-SNAPSHOT.json` | 공개 주소와 원본 소스 커밋 |
| `server.mjs` | 설치 없이 실행하는 로컬 정적 서버 |
