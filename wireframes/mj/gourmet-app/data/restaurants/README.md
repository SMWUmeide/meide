# Osteria La Solita Zuppa 공식 메뉴

공식 주소: https://11729.ordinaincloud.it/menu/13361/products

`solita-zuppa-raw.json`은 공개 WEB_MENU 조회로 받은 970개 상품의 공식 자료입니다. `solita-zuppa.json`은 상품 ID를 보존한 한국어 번역·사진 URL·가격·분류 자료입니다. 설명이 있는 866개 항목은 공식 원문을 번역하고, 설명이 없는 항목은 없다고 표시합니다. 사진이 등록된 866개 항목은 해당 상품 ID의 이미지에 연결하며 나머지 항목에 다른 음식 사진을 대신 넣지 않습니다. 여러 사진이 있으면 모든 원본 URL을 보존하고 첫 사진을 앱 대표 사진으로 사용합니다.

이 자료는 조회 시점의 메뉴이며 실제 메뉴·가격·사진은 바뀔 수 있습니다. 촬영 메뉴판 해석에 연결할 때 촬영 가격은 유지하고 공식 웹 가격은 별도 보존합니다. 음식명은 정규화된 정확 일치 또는 유일한 긴 이름의 접두부 일치만 허용합니다. 모호하거나 없는 음식은 기존 촬영 해석을 그대로 유지합니다.

공식 설명에 명시된 재료·조리법·맛만 별도 필드로 저장합니다. 알레르기 안전성을 보장하지 않으며 알레르기는 식당에 확인해야 합니다. 원문과 사진 제공자는 식당/공식 메뉴 사이트이며 출처 링크를 함께 표시합니다.

## 자료 갱신

앱 디렉터리에서 `node scripts/fetch-solita-menu.mjs`로 전체 공식 자료를 다시 조회합니다. 기존 번역을 새로 만들 때는 solita-zuppa.json을 별도로 보관하고 제거한 뒤 `node --env-file=.env scripts/build-solita-catalog.mjs`를 실행하세요. Gemini 호출이 발생하며 중간 저장한 항목부터 이어서 실행할 수 있습니다. 갱신 후 테스트하고 서버를 재배포하세요. 런타임에는 이 식당의 공식 설명을 매번 다시 번역하지 않습니다.
