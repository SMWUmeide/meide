# 한입 유럽 — 한국어 유럽 미식 가이드

## 자동 카메라 연결 (2026-10-10)

촬영 화면에 들어가면 카메라를 자동 요청합니다. `카메라 켜기`, `카메라 앱으로 촬영` 버튼은 제거했습니다. 사진 촬영·추가·삭제로 화면이 갱신되어도 같은 카메라 연결을 재사용해 연속 촬영할 수 있습니다. 촬영 화면을 나가거나 페이지를 닫으면 카메라를 종료합니다.

카메라 권한은 브라우저/운영체제가 관리합니다. 첫 요청에서 이 사이트를 계속 허용하도록 선택하면 이후 진입 시 저장된 권한으로 바로 연결합니다. 브라우저가 일회성 권한만 제공하거나 사용자가 차단·초기화한 경우에는 다시 허용해야 하며, 앱이 이를 강제로 우회하지 않습니다. 실제 휴대폰 접속은 HTTPS가 필요합니다.

사진의 AI 전송 동의도 한 번 선택하면 이 브라우저에 기억합니다. 이후 촬영에서는 동일한 동의를 반복해서 묻지 않습니다. MY의 기기 저장 데이터 삭제 시 이 동의도 초기화합니다.

## 여행지 검색 (2026-10-10)

홈의 위치 버튼은 이제 **여행지 선택** 화면으로 연결됩니다. 현재 여행지, 검색창, 인기 여행지 6개 카드, 하단 설정 버튼을 첨부 이미지처럼 배치했습니다. 인기 여행지는 로마·파리·바르셀로나·런던·프라하·리스본입니다. 일본·미국 등 유럽 밖 예시를 넣지 않았습니다.

국가명은 유럽과 유럽에 걸친 국가 및 부속 여행 지역 58곳을 포함합니다. 도시·마을·도시 내 지역 지명 **1,022,909곳**, 검색 별칭 **2,523,982개**를 GeoNames 국가별 전체 자료에서 추출해 로컬 데이터베이스에 포함했습니다. 인구 500명 이하의 마을도 포함하고, 역사 지명·폐허·미거주/파괴된 거주지 유형은 제외했습니다. 이 수치는 공식 행정도시 개수가 아니라 GeoNames의 거주 지역 지명 수입니다. 도시 이름·영문·현지어·한국어 별칭을 검색하며, 지명과 일치하는 결과를 먼저 표시합니다. 한국어 별칭이 없는 지명은 영문/현지어로 검색할 수 있습니다.

국가를 검색하면 일부 인기 도시만이 아니라 그 국가의 도시·마을·지역 **전체 목록**을 60개씩 보여줍니다. `도시 더 보기`로 다음 결과를 계속 불러옵니다. 국가 결과를 누르면 국가 안에서 도시를 검색하는 모드가 열립니다. 국가 필터의 × 버튼으로 유럽 전체 검색으로 돌아갑니다. 국가 선택·도시 검색은 외부 API 키나 인터넷 연결 없이도 작동합니다. 최초 화면의 인기 여행지 6개는 그대로 유지합니다.

자료 파일은 `data/europe-cities.sqlite`(약 250MB), 집계·출처는 `data/city-data-info.json`입니다. GeoNames CC BY 4.0 자료를 변환한 것이며 화면 하단과 이 문서에 출처를 표시합니다. 원본 제공자는 정확성·최신성·완전성을 보장하지 않으므로 모든 현실 지명이 빠짐없이 존재한다고 보장하지는 않습니다. [GeoNames 자료와 라이선스](https://download.geonames.org/export/dump/readme.txt).

새 자료로 다시 만들려면 Python이 있는 환경에서 프로젝트 디렉터리의 `scripts/download-geonames.py` 후 `scripts/build-city-database.py`를 실행하고 서버를 재시작합니다. 제공된 데이터베이스로 시작할 때는 다운로드나 재생성이 필요 없습니다. 데이터베이스 파일을 제거하면 이전 Open-Meteo 외부 검색 경로로 돌아가므로 전체 자료 파일을 함께 보존하세요.

선택한 여행지는 설정 버튼을 누를 때만 확정되며 이 브라우저에 저장됩니다. 검색 화면에서 뒤로 가면 이전 여행지를 유지합니다. 여행지 선택은 여행 계획용이며 실제 GPS 위치를 바꾸지 않습니다.

[Figma 여행지 선택 화면](https://www.figma.com/design/EyR8e24IyNMuHpg5Z617dc?node-id=348-9)을 기존 수정 페이지에 추가했습니다. 홈 위치 버튼에도 프로토타입 이동 연결을 넣었습니다. 전체 수정 화면은 이제 14개입니다.

## 디자인 수정본 (2026-10-10)

첨부한 원본 8개 UI의 화면 배치와 사진 영역을 유지하고, 캐치테이블 참고 이미지의 오렌지/화이트 색상, 검정 본문, 선 아이콘, 둥근 카드와 버튼 스타일을 적용했습니다. 메뉴 상세는 배경 메뉴가 보이는 모달로 변경했습니다. MY 화면은 프로필·저장 수·카드 형태로 구성했습니다.

[Figma 수정본](https://www.figma.com/design/EyR8e24IyNMuHpg5Z617dc?node-id=341-23): 기존 파일의 **한입 유럽 · 캐치테이블 스타일 수정본** 페이지입니다. 기존 8개 원본 화면은 보존했습니다. 새 페이지에는 총 13개 360×780 화면, 색상 변수, 텍스트 스타일, 추가 화면용 공유 버튼 컴포넌트를 만들었습니다. 글자·버튼·아이콘·개별 사진 영역은 실제 레이어로 편집할 수 있습니다. Figma에서 수정한 디자인이 웹 코드에 자동 반영되지는 않습니다.

웹 예시 화면 바로보기: `/?design=menu`, `/?design=review`, `/?design=detail`, `/?design=cart`, `/?design=order`, `/?design=staff`, `/?design=capture`, `/?design=restaurant`. 이 주소는 디자인 검토용 예시 데이터만 사용하며 상단에 데모 안내를 표시합니다. 정상 흐름은 `/`에서 시작하세요.

예시 음식 사진은 사용자의 원본 Figma에서 개별 사진 영역만 가져왔으며, 음식과의 일치나 실제 식당 음식 사진임을 보장하지 않습니다. 화면 전체를 사진으로 붙이지 않았습니다. 실제 연동 모드의 사진/출처 조회 우선순위는 기존과 동일합니다.

업로드된 8개 참고 UI의 기능 흐름을 바탕으로 만든 모바일 웹 프로토타입입니다. 기존 프로젝트의 `sources/` 파일은 수정하지 않았습니다. 별도 설치 패키지 없이 Node.js 내장 기능으로 실행합니다.

## 실행

Node.js 22.13 이상 (권장: 24 이상)을 권장합니다. 터미널에서 이 디렉터리로 이동한 후:

```sh
cp .env.example .env
npm start
```

`http://localhost:3000`을 엽니다. `npm install`은 필요하지 않습니다. Node.js가 PATH에 없는 현재 Codex 환경에서는 아래 명령으로 실행할 수 있습니다.

```sh
/Users/kimminju/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node --env-file-if-exists=.env server.mjs
```

이미 서버가 실행 중이면 해당 주소를 열면 됩니다. 설정을 바꾼 뒤 서버를 재시작하세요. 포트 변경은 `.env`의 `PORT`로 설정합니다.

## 환경변수

| 변수 | 용도 |
|---|---|
| `OPENAI_API_KEY` | 실제 사진의 OCR/AI 분석, 웹 검색, 한국어 해석, 현지어 주문 및 한글 참고 발음 |
| `OPENAI_MODEL` | 이미지 입력과 Responses 웹 검색을 지원하는 모델. 기본값 `gpt-4.1` |
| `GOOGLE_PLACES_API_KEY` | Places API (New)의 Text Search, Nearby Search, Place Details, Place Photos. Google Cloud에서 API 활성화와 결제 설정 필요 |
| `GOOGLE_SEARCH_API_KEY` | 선택 사항. Google Custom Search JSON API 이미지 검색 |
| `GOOGLE_SEARCH_ENGINE_ID` | 이미지 검색이 활성화된 Programmable Search Engine ID |
| `PORT`, `HOST` | 기본 `3000`, `127.0.0.1` |

키는 `.env` 또는 서버 환경변수에만 넣습니다. `.env`는 Git 제외 대상이며 브라우저로 전달하지 않습니다. OpenAI/Google API 사용료는 각 계정에 청구됩니다. Custom Search 접근은 계정과 서비스 제공 범위에 따라 사용이 불가능할 수 있으며, 실패하면 Places 사진 또는 사진 없음으로 표시합니다.

## 모바일에서 사용

Galaxy S25용 기준 테스트 크기는 CSS 360×780입니다. 실제 브라우저의 화면 크기, 글자 크기, 주소 표시줄에 따라 높이는 달라집니다. 320px부터 넓은 화면까지 반응형이며, 데스크톱에서는 최대 430px 모바일 패널로 표시합니다.

실제 휴대폰 라이브 카메라와 GPS는 **HTTPS 주소**에서 접속해야 합니다. 로컬 컴퓨터의 localhost는 컴퓨터에서만 접근할 수 있습니다. 휴대폰 테스트는 이 서버를 HTTPS 리버스 프록시 뒤에 배치하세요. HTTP LAN 주소에서는 라이브 카메라/GPS가 제한됩니다. 기본 loopback 바인딩을 변경해야 하며, `HOST=0.0.0.0`으로 설정할 경우 같은 네트워크에서 접속 가능하므로 신뢰할 수 있는 테스트 네트워크에서만 사용하세요. 서버는 인증·사용량 제한이 없는 개발용이므로 인터넷에 그대로 공개하지 마세요.

자동 연결되는 라이브 카메라와 `갤러리에서 선택`을 지원합니다. 사진은 최대 6장, 원본 20MB 이하, JPG/PNG/WebP로 제한하고 브라우저에서 긴 변 1800px의 JPEG로 압축합니다. HEIC는 지원하지 않습니다. 실제 동작은 기기/브라우저의 파일 선택기와 권한에 따라 다릅니다.

## 구현 흐름

1. 홈 → 자동 라이브 카메라 / 갤러리 → 사진 추가·삭제.
2. 전송 동의 후 사진을 Responses API 이미지 입력으로 OCR 및 분석. 메뉴에 적힌 식당명만 추출하며 읽히지 않은 메뉴나 가격을 만들어내지 않습니다.
3. 읽은 식당명으로 Google Places 검색. 이름이 없으면 GPS 기반 1km 이내 거리순 후보, 수동 검색, 미확인 이름 입력, 건너뛰기 지원. 모든 후보는 사용자 확인을 거칩니다.
4. 사진 확인 → 공식 웹 메뉴 우선 검색 및 해석 → 부족한 메뉴에 웹 검색. 웹 검색이 반환한 출처와 일치하는 URL만 표시.
5. 메뉴 목록·상세 → 수량 선택·찜 → 장바구니 → 현지어 주문 문장·한글 발음·음성 읽기 → 직원용 큰 글씨.
6. 홈 / 찜한 음식 / 주문 내역 / 동반인 / 마이페이지 5개 탭. 찜·주문 문장·동반인 메모는 localStorage에 저장. 자동 주문·결제는 하지 않습니다.

## 정보와 이미지 출처

공식 웹사이트는 사용자가 확인한 Places ID의 Place Details에서 얻으며 공식 도메인으로 웹 검색을 제한합니다. 접근 불가, 스캔 PDF, 검색 색인 누락 등으로 설명을 얻지 못하면 일반 웹 음식 정보로 보완합니다. 공식 설명이 확보되지 않은 메뉴는 AI의 일반 설명을 유지하고 추정 안내를 표시합니다. 재료와 알레르기 정보는 확정 안전 판정을 하지 않습니다. 원문 전체를 복제하지 않고 한국어 해석/요약과 출처 링크를 제공합니다.

이미지 우선순위는 공식 사이트 이미지 검색 → Places가 제공한 식당 사진 → CC 조건으로 필터링한 대표 음식 웹 이미지 → 사진 없음(아이콘)입니다. 공식/Places 사진이 특정 음식이라는 시각적 검증은 하지 않으므로 식당 참고 사진·음식 일치 미확인으로 표시합니다. 일반 이미지는 실제 식당 음식이 아닌 참고 이미지임을 표시합니다. 원문과 이용조건 링크를 함께 제공합니다. 검색 필터만으로 라이선스가 보장되지는 않으므로 외부 배포 전 실제 권리 조건을 확인해야 합니다. 사진 링크가 만료되거나 차단되면 아이콘으로 대체합니다.

Google Maps 페이지/리뷰 사진을 스크래핑하지 않습니다. Places API가 반환한 사진 리소스만 사용하고 작성자 귀속과 Google Maps 원본 링크를 노출합니다. 사진 리소스나 Places 정보를 영구 저장하지 않습니다. 동반인/주문 내역에는 Google 식당 결과를 저장하지 않으며 찜에는 Places 사진을 저장하지 않습니다.

## 데모와 실패 처리

키가 없으면 상단에 데모 모드를 명시합니다. `예시 메뉴로 먼저 체험`만 미리 작성한 3개 메뉴를 사용합니다. **업로드한 실제 사진의 결과를 예시 메뉴로 대체하지 않습니다.** AI 키가 없으면 실제 인식 버튼의 실행 결과로 명확한 오류가 나옵니다. Places 키가 없으면 가짜 GPS 후보를 만들지 않고 직접 입력/건너뛰기를 안내합니다. 키가 일부만 설정되면 부분 연동 상태를 표시합니다. 웹 검색/이미지 조회가 실패해도 촬영에서 읽은 음식 정보를 유지합니다.

사진은 서버 디스크에 저장하지 않습니다. OpenAI API로 사진이 전송되며 공급자의 처리 정책이 적용됩니다. 인식 결과는 서버 메모리에서 30분 만료하고 최대 200세션으로 제한됩니다. 서버 재시작 후 기존 인식 세션은 만료되어 재촬영/선택이 필요합니다. GPS 좌표는 요청 중에만 사용하고 저장하지 않습니다. 브라우저 음성 읽기는 설치된 언어 음성의 영향을 받습니다.

## 무료 OCR + Google Places 선택 연결

Google Places는 GOOGLE_PLACES_API_KEY와 ENABLE_GOOGLE_PLACES=true 두 설정이 필요합니다. 기본 월 호출 제한은 이름 검색100/주변검색100/사진300이며 data/google-usage.sqlite에 재시작 후에도 유지합니다. 이 제한은 이 앱의 호출만 계산하므로 같은 결제계정의 다른 프로젝트 사용량은 별도 확인해야 합니다. Google Cloud의 할당량도 함께 제한하세요. 검색 필드에서 웹사이트/리뷰 등 Enterprise 필드를 제외했습니다. OCR 식당명 후보는 휴리스틱이며 사용자 확인 후 검색합니다. 사진은 작성자와 Google Maps 원문 링크를 제공하며 사용자가 메뉴별로 지정합니다. 음식 일치는 자동 검증하지 않습니다.

## 공식 웹 메뉴 추출

촬영 썸네일/확인 사진 클릭으로 확대, 100~400% 확대 및 스크롤을 지원합니다. 촬영 후 버튼은 해석된 메뉴판 만들기. 한국어 음식 사전은 대표 유럽 요리별 설명을 제공하며 식당별 조리법으로 확정하지 않습니다. 일반 Google 이미지 자동검색은 신규 Custom Search API 가입 중단으로 구현되지 않았으며 메뉴별 Google 이미지 검색 링크를 제공합니다. 사전에 없는 음식명을 임의로 번역하지 않습니다.

Gemini: GEMINI_API_KEY 등록 시 사진 해석 사용. gemini-3.8-flash 기본 모델, 월100회 앱 제한. 무료 티어 적용 여부는 AI Studio 프로젝트 결제 상태에 달려 있으며 앱이 유료 프로젝트를 무료로 전환하지는 않습니다. 사진 전송 동의 별도 저장, 일반 설명/알레르기는 추정 표시, 검색 도구 미사용.

실제 연결 테스트: Gemini 3.1 Flash-Lite로 테스트 메뉴 사진 2개 음식명/한국어 해석/16.00 및14.50 가격 확인 성공. 3.8 Flash는 지연 때문에 기본 모델을3.1 Flash-Lite로 변경했습니다.

### 장바구니의 팁 예상
메뉴 더 담기와 다 골랐어요 버튼을 제거하고, 원어 → 한국어 음식명 → 가격 → 수량 순으로 표시합니다. 실제 식당의 국가(주소/공유된 국가 정보)를 선택한 여행지보다 우선합니다. 확인한 지역 기준은 이탈리아 10%, 영국 12.5%, 오스트리아 10%, 독일 10%, 포르투갈 5%, 프랑스 자동 팁 0%이며 모두 선택 팁의 예상치입니다. 서비스료가 이미 포함됐거나 팁을 원하지 않으면 체크를 해제합니다. 아직 기준이 등록되지 않은 지역은 자동 합산하지 않고 수동 비율을 고를 수 있게 합니다. 팁은 센트 단위로 반올림하고, 원화는 최신 ECB 고시 환율로 음식+팁 총액을 계산합니다. 가격이 읽히지 않은 음식은 미확인 가격 별도로 표시합니다. 정책별 근거 URL은 public/tip-policy.js에 기록했습니다.
