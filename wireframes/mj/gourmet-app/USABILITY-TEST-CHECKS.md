# 사용성 테스트 고정 메뉴 검증

기본 활성화. 사진 촬영·추가·삭제는 유지하며 사진 인식 대신 로컬 공식 메뉴를 사용합니다. 사진 해석 버튼 → Osteria La Solita Zuppa 식당 확인 → 맞아요 → 메뉴로 즉시 이동합니다. `USABILITY_TEST=false`로 원래 인식 흐름으로 돌아갈 수 있습니다. 사진은 이 모드에서 AI로 전송하지 않습니다.

- Zuppe: 수프 4개
- Secondi: 메인 요리 12개
- Vino rosato: 로제 와인 14개
- 총 30개. 과거 식사 평가가 카테고리를 재분류하지 않도록 고정했습니다.

## 출처와 사진

공식 상품 API의 카테고리 ID와 저장된 이미지 URL을 대조했습니다. 공식 이미지 29개는 다운로드한 원본을 로컬에 보관해 보여줍니다. 음식 16개는 기존 로컬 파일과 원본 바이트가 일치했고, 와인 13개의 사진을 로컬에 추가했습니다. 귀도티 로제는 공식 사진이 없어 사진을 만들어 넣지 않습니다. 상품별 검증 결과는 `data/restaurants/solita-usability-audit.json`에 있습니다. 현재 API에서 상품 조회가 되지 않는 항목은 2026-10-10에 저장한 공식 원본과 대조했습니다.

## 한국어 해석

30개 설명을 공식 원문과 대조했습니다. 로제 14개는 재배·양조 용어의 긴 직역을 줄이고 품종·향·맛·음식 조합 중심으로 정리했습니다. 공식 원문에 없는 맛은 만들지 않았습니다. 소의 위와 곱창을 구분하고 피렌체식 대구의 튀김 조리법을 명시했습니다. 멧돼지 제목/노루 설명, 포르치니 제목/다른 채소 설명, A 와인의 2024 판매명/2017 설명, 알리키의 2022 설명 등 원문 불일치는 사용자에게 표시합니다. 공식 설명 자체의 오류까지 확정할 수는 없습니다.

## 동작 확인

일반 사진 선택 → 식당 확인 → 맞아요 → 30개 메뉴, 세 카테고리 표시를 브라우저에서 확인했습니다. 기존 자동 테스트 55개와 고정 메뉴 테스트 1개가 통과했습니다. 실제 휴대폰 카메라 권한과 기기 촬영은 별도 실물 확인이 필요합니다.

## 메뉴 화면·설명 보완 (2026-10-11)

동반인 안내를 카테고리 위에 두고 중복 ‘메뉴’ 줄을 제거했습니다. 분류 띠는 `zuppe 수프`, `secondi 메인 요리`, `vino rosato 로제 와인`으로 표시합니다. 원문과 한국어는 모두 12px·일반 굵기이며 원문은 회색, 한국어는 검은색입니다. 설명은 문장 단위로 줄을 나누고 목록의 3줄 생략을 제거했습니다.

음식 16개 모두 주재료·소스/양념·조리법 정보를 점검했습니다. 리크를 부추로 적었던 재료명, 비어 있던 닭고기·소고기 재료 정보를 바로잡았습니다. 공식 원문에 없는 소스 배합·향신료 종류·가열 시간은 임의로 확정하지 않습니다. 소 볼살·닭고기·오소부코에는 아래 검색 자료를 바탕으로 상세 화면에 ‘일반 조리법 참고’를 추가하고 식당 실제 레시피와 구분했습니다.

- https://ricette.giallozafferano.it/Guancia-di-manzo-brasata.html
- https://www.cucchiaio.it/ricetta/pollo-speziato/
- https://ricette.giallozafferano.it/Ossibuchi-alla-milanese.html

식당 확인 화면은 첨부 참고 이미지에 맞춰 기존 안내문·주소·실제 Google 지도·맞아요/내 위치/건너뛰기 버튼을 복원했습니다. 지도 임베드에서 해당 식당 위치가 표시되는 것을 확인했습니다. 고정 메뉴 설정은 유지합니다.
