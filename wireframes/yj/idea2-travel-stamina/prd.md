# PRD — 여행 체력 지도

Oct 4, 2026 · @노연주

## 개요

### 한 줄 정의

가기 전에 얼마나 힘든 곳인지 알려주고, 힘들 때 어디서 쉴지 알려주는 중장년 부부의 여행 체력 지도.

### 제품 목표

관광지마다 계단·경사, 그늘, 앉을 곳, 관람 시간 같은 체력 정보를 한국어로 정리해 보여주고, 덜 힘들게 보는 방법을 함께 알려준다. 스마트워치와 연계해 관광 중에는 폰을 꺼내지 않고 손목에서 정보를 확인하게 하고, 사용자들이 실제로 걸은 기록을 모아 체력 정보를 더 정확하게 만든다. 여행 중에는 지금 위치 근처의 벤치, 앉을 수 있는 실내, 화장실을 찾게 해 지친 순간에 바로 쉬게 한다. 사용자가 무리하지 않고 계획한 일정을 끝까지 즐기는 것을 목표로 한다.

### 배경

여행에서 무리하게 되는 가장 큰 이유는 가보기 전엔 그곳이 얼마나 힘든지 모르기 때문이다. 계단만 있는 전망대, 그늘 없는 유적지, 입장 줄이 긴 박물관은 현장에서야 알게 된다. 또 유럽은 벤치가 적고 화장실이 유료이거나 찾기 어려워, 지쳐도 막상 쉴 곳이 없는 경우가 많다.

## 문제 및 해결 방안

### 디자인 챌린지와 HMW

- **디자인 챌린지:** 중장년층이 자유 해외여행 시 현지에서 겪는 어려움을 어떻게 해소할 수 있을까?
- **HMW:** 어떻게 하면 여행자의 체력을 고려해 여행 중에도 유연하게 일정을 조정할 수 있을까?

### 사용자 문제

1. 관광지가 얼마나 힘든지(계단·경사, 그늘, 입장 줄, 관람 시간) 가보기 전엔 알 수 없어 무리한 일정을 짠다.
2. 엘리베이터 입구, 덜 붐비는 시간처럼 덜 힘든 방법이 있어도 정보가 흩어져 있고 대부분 외국어다.
3. 지쳐도 근처에 앉을 곳이나 화장실을 찾기 어렵다. 유럽은 벤치가 적고 화장실이 유료인 곳이 많다.
4. 기존 후기는 젊은 여행자 기준이라 "할 만하다"는 말이 중장년에게는 맞지 않는다.

### 해결 방안

- **장소 체력 카드:** 장소마다 체력에 영향을 주는 정보를 항목별로 한국어로 보여준다.
- **덜 힘든 방법:** 엘리베이터 입구, 덜 붐비는 시간, 짧은 관람 동선 같은 팁을 함께 알려준다.
- **하루 체력 요약:** 담아둔 일정의 체력 카드를 합쳐 "오늘은 힘든 날"을 미리 보여주고, 힘든 곳이 몰려 있으면 순서 변경을 제안한다.
- **쉴 곳 지도:** 지금 위치 근처의 벤치, 앉을 수 있는 실내, 화장실, 그늘을 보여준다.
- **워치 연계:** 장소에 도착하면 워치에 체력 카드 요약이 뜨고, 워치 버튼 하나로 가장 가까운 쉴 곳을 찾는다. 동의한 사용자의 걸음 기록은 익명으로 모여 체력 카드의 실측 데이터가 된다.
- **한 탭 체감 평가:** 다녀온 뒤 "생각보다 힘들었어요"를 남겨 중장년 기준의 정보가 쌓이게 한다.

### 차별점

- 장소 정보를 **체력 관점**으로 다시 정리한다. 지도 앱은 위치와 평점을, 후기는 감상을 주지만 "얼마나 힘든가"를 한눈에 주는 곳은 없다.
- **느낌과 실측을 함께** 쌓는다. 한국인 중장년의 한 탭 체감 평가에 워치로 모은 실제 걸음 수·오르내린 높이가 더해져, 후기만으로는 알 수 없는 정확한 정보를 만든다.
- **관광 중에는 손목에서** 끝난다. 도착 요약과 쉴 곳 찾기를 워치에서 해결해 폰을 꺼낼 일을 줄인다.
- 정보마다 **출처와 기준**(공식 안내, 후기 수, 실측 인원)을 표시해 믿고 쓸 수 있게 한다.

## 경쟁 분석

체력 정보는 이미 여러 곳에 있지만 흩어져 있고, 체력 관점으로 정리해 주는 서비스는 없다. 이 서비스는 그 정보를 모아 한 장의 카드로 보여주는 위치에 선다.

| 구분 | 잘하는 것 | 부족한 것 |
| --- | --- | --- |
| 구글 지도 | 위치, 평점, 시간대별 혼잡도, 보통 머무는 시간 | 계단·그늘·앉을 곳 같은 체력 정보가 없거나 흩어져 있음 |
| 여행 블로그·리뷰 | 실제 체감("계단 많음", "그늘 없음") | 찾고 읽는 데 시간이 들고, 젊은 여행자 기준이 많음 |
| 관광지 공식 접근성 안내 | 엘리베이터, 계단 없는 동선 등 정확한 시설 정보 | 외국어, 장애인용 정보로만 인식돼 일반 여행자는 찾지 않음 |
| 이 서비스 | 위 정보를 체력 카드 하나로 한국어 정리, 근처 쉴 곳 연결 | 초기 데이터 범위가 좁음 |

## 타겟 및 시나리오

### 타겟 사용자

자녀가 성장한 뒤 둘이서 해외 자유여행을 다니기 시작한 50대 중후반 부부. 두 사람 모두 스마트폰과 스마트워치 사용에 익숙하다.

| 퍼소나 | 나이 | 여행 성향 | 체력 |
| --- | --- | --- | --- |
| 박성호 | 56세 | 최대한 많이 보려 함, 계획은 꼼꼼하지만 현장에서 오래 머물기도 함 | 비교적 좋음 |
| 최미연 | 54세 | 여행 자체는 좋아함 | 성호보다 약하고 후반으로 갈수록 피로가 빨리 쌓임 |

### 핵심 시나리오 — 로마 하루 일정

1. **여행 전날 밤:** 성호가 다음 날 갈 콜로세움, 포로 로마노, 트레비 분수, 스페인 광장을 앱에 담는다.
2. **체력 요약 확인:** 앱이 "내일은 힘든 날이에요"라고 알려준다. 포로 로마노 카드에 "많이 걸음 · 그늘 적음 · 돌길과 경사"와 함께 워치 기록 기준 평균 걸음 수가 표시된다.
3. **덜 힘든 방법:** 카드 아래에 "더운 오후보다 오전 방문 추천" 팁이 있다. 두 사람은 포로 로마노를 오전으로 옮긴다.
4. **손목에서 확인:** 다음 날 포로 로마노에 도착하자 두 사람의 워치가 한 번 울리고 "많이 걸음 · 그늘 적음 · 앉을 곳 입구 쪽" 요약이 뜬다. 폰은 꺼내지 않는다.
5. **지친 순간:** 볼거리가 많아 오래 걷다 미연이 지친다. 미연이 워치의 쉴 곳 버튼을 누르자 가장 가까운 쉴 곳 3곳이 뜨고, 그늘 벤치를 고르자 진동으로 방향을 안내받는다.
6. **쉬고 이동:** 20분 쉬고 트레비 분수로 이동한다.
7. **체감 평가:** 저녁에 앱이 "포로 로마노 어땠어요?"라고 묻고, 미연이 "생각보다 힘들었어요"를 누른다. 오늘 걸은 기록도 익명으로 더해진다.
8. **마무리:** 미연: "어디가 힘든지 미리 알고 가니까 덜 지쳤어. 쉴 데도 손목에서 바로 찾았고."

## 주요 기능 범위

여행 전에는 체력 카드와 하루 요약으로 일정을 정하고, 여행 중에는 체력 카드 확인과 쉴 곳 찾기로 대응한다.

| 시점 | 기능 | 설명 | 우선순위 |
| --- | --- | --- | --- |
| 전·중 | 장소 체력 카드 | 걷는 양, 계단·경사, 그늘, 앉을 곳, 관람 시간, 붐비는 시간을 항목별로 표시, 출처 함께 표기 | P0 |
| 전·중 | 덜 힘든 방법 | 엘리베이터 입구, 덜 붐비는 시간, 짧은 관람 동선 등 팁 | P0 |
| 중 | 쉴 곳 지도 | 현재 위치 근처 벤치, 앉을 수 있는 실내(성당·공원 등), 화장실(유료 여부), 그늘을 거리순으로 표시 | P0 |
| 중 | 워치 도착 요약 | 장소에 도착하면 워치에 체력 카드 핵심 3줄 표시 | P0 |
| 중 | 워치 쉴 곳 바로가기 | 워치 버튼 하나로 가장 가까운 쉴 곳 3곳, 선택하면 진동 방향 안내 | P0 |
| 전 | 장소 담기 | 날짜별로 갈 장소를 담음 | P1 |
| 전 | 하루 체력 요약 | 담은 장소의 카드를 합쳐 하루 강도를 보여주고, 힘든 곳이 몰려 있으면 순서 변경 제안 | P1 |
| 후 | 한 탭 체감 평가 | 방문 후 "편했어요 / 비슷했어요 / 힘들었어요" 중 하나를 남김 | P1 |
| 중·후 | 워치 걸음 기록 수집 | 동의한 사용자의 장소별 걸음 수, 오르내린 높이, 머문 시간을 익명 집계해 체력 카드에 실측 평균으로 표시 | P1 |
| 중 | 많이 걸었을 때 쉴 곳 안내 | 평소보다 훨씬 많이 걸으면 워치로 "근처에 쉴 곳이 있어요"만 알림 (컨디션 판단·질문 없음) | P2 |
| 전·중 | 날씨 연동 | 더운 날에는 그늘 없는 장소에 경고 | P2 |
| 중 | 오프라인 저장 | 데이터가 약한 곳에서도 담은 장소의 카드 확인 | P2 |

P0는 핵심 시나리오에 반드시 필요한 기능, P1은 흐름을 매끄럽게 하는 기능, P2는 범위가 허락하면 추가할 기능이다.

| 정보 | 출처 | 비고 |
| --- | --- | --- |
| 엘리베이터, 계단 없는 동선, 휴게 공간 | 관광지 공식 홈페이지의 접근성 안내 | 장애인용 안내를 중장년의 "덜 힘든 방법"으로 활용 |
| 계단, 벤치, 화장실 위치 | 오픈스트리트맵 공개 지도 데이터 | 쉴 곳 지도의 기본 데이터 |
| 관람 시간, 붐비는 시간 | 구글 지도의 보통 머무는 시간, 시간대별 혼잡도 |  |
| 체감 난이도("계단 많음", "그늘 없음") | 한국인 여행 블로그, 구글 리뷰를 AI로 요약 | 항목별 태그로 정리 |
| 중장년 기준 체감 | 앱 사용자의 한 탭 평가 | 시간이 지날수록 정확해짐 |
| 실제 걸음 수, 오르내린 높이, 머문 시간 | 동의한 사용자의 스마트워치 기록 (익명, 장소별 평균만 집계) | 체감 평가와 짝을 이뤄 "느낌 + 실측"으로 표시 |

**초기 범위:** 로마 주요 관광지 10\~20곳을 팀이 직접 조사해 채운 버전으로 시작한다.

## 성공·위험 요소

### 핵심 지표

- **체력 카드 조회율:** 담은 장소 중 체력 카드를 열어본 비율
- **일정 변경 반영률:** 하루 요약의 순서 변경 제안이나 덜 힘든 방법을 실제로 반영한 비율
- **쉴 곳 지도 사용 횟수:** 여행 중 쉴 곳을 찾아 길찾기까지 이어진 횟수
- **체감 평가 참여율과 일치도:** 평가를 남긴 비율, 그리고 카드의 난이도와 사용자 체감이 맞는 정도

### 리스크와 대응

| 리스크 | 대응 |
| --- | --- |
| 정보가 틀리거나 오래됨 (공사, 엘리베이터 고장) | 항목마다 출처와 기준일 표시, 사용자 제보·평가로 보완 |
| 초기 데이터가 부족함 | 로마 주요 관광지 10\~20곳으로 범위를 좁혀 직접 조사 |
| 체력은 사람마다 달라 난이도가 안 맞음 | 점수 하나로 단정하지 않고 "계단 많음", "그늘 적음" 같은 사실 정보로 보여줌 |
| 공개 지도 데이터에 벤치·화장실이 빠져 있음 | 출처 표시, 사용자가 쉴 곳을 추가 제보할 수 있게 함 |
| 구글 지도와 겹친다는 지적 | 위치가 아니라 "얼마나 힘든가"를 정리한다는 점, 한국인 중장년 체감을 쌓는다는 점을 내세움 |
| 워치 기록에 대한 개인정보 우려 | 동의한 경우에만 수집하고, 개인 식별 없이 장소별 평균만 저장. 설정에서 언제든 끌 수 있음 |
| 워치가 없는 사용자 | 모든 핵심 기능은 폰만으로도 사용 가능하게 하고, 워치는 편의 기능으로 둠 |
