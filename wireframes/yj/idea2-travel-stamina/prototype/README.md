# 프로토타입 — 여행 체력 지도

`index.html`을 브라우저로 열면 폰 7개, 워치 3개 화면을 한눈에 볼 수 있어요. 각 화면의 "새 창으로 열기"를 누르면 그 화면부터 버튼을 눌러 다음 화면으로 넘어가 볼 수 있어요.

- `index.html` — 전체 화면 모아보기
- `*.dc.html` — 화면 하나하나 (서로 링크로 연결)
- `support.js` — 화면을 그려주는 실행 파일 (지우면 안 열려요)

`[n]`, `[성당 이름]`처럼 대괄호로 된 값은 로마 관광지 조사 후 채울 자리예요.
