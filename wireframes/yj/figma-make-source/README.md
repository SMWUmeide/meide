# YJ 프로토타입 소스 (React + Vite + Tailwind)

`../figma-make-prototype/` 에 있는 프로토타입의 원본 소스입니다.
(원본: https://github.com/SMWUmeide/YJ 에서 가져와 수정한 버전)

## 수정 후 다시 빌드하기
```bash
cd wireframes/yj/figma-make-source
pnpm install
bash build.sh
```
사진·아이콘 에셋은 용량 때문에 이 폴더에 중복 저장하지 않고, `../figma-make-prototype/assets/` 에서 가져옵니다.
