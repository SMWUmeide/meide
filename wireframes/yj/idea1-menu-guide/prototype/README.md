# 프로토타입 — 유럽 미식 가이드

`index.html`을 브라우저로 열면 바로 눌러볼 수 있어요. 로그인부터 동반인 추가, 입맛·알레르기, 메뉴판 촬영, 한글 메뉴판, 주문, 미식 가이드, 식사 후 평가까지 한 흐름으로 이어져요.

- `index.html` — 프로토타입 본체 (화면 20개)
- `images/` — 메뉴 음식 사진
- `support.js` — 화면을 그려주는 실행 파일 (지우면 안 열려요)
