# **기능명세서 — 한국인의 감각으로 풀어주는 유럽 미식 가이드**

## **요구사항 구조**

수정된 PRD를 기준으로 요구사항 8개를 "요구사항 → 기능 → 상세 기능" 3단계로 정리했다. 

| 번호 | 요구사항 | 역할 |
| :---- | :---- | :---- |
| 1 | 여행 전 준비 | 차별점: 여행 전부터 이어지는 흐름 |
| 2 | 위치 기반 음식 추천 받기 |  |
| 3 | 메뉴판 촬영 및 한식 해석 | 핵심 흐름 |
| 4 | 메뉴판 | 한국인을 위한 해석된 메뉴판 |
| 5 | 주문 하기 | 기본기 \+ 동반인 설정 |
| 6 | 미식 가이드 | 기본기 |
| 7 | 식사 후 평가 | 차별점: 개인화  |
| 8 | 설정 (마이페이지) | 핵심 흐름 |

우선순위는 필수(MVP에 반드시 포함), 권장(시간이 되면 포함), 선택(후순위)으로 표시한다.

## **1\. 여행 전 준비**

출발 전에 여행지와 알레르기를 설정하고, 식당 이용법을 읽고, 먹어볼 음식을 찜해 두는 단계다.

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 1.1 | 온보딩 및 로그인 | 첫 실행 시 로그인 및 별명 설정 | 필수 |
| 1.1.1 | 동반인 추가  | 동반인 이름(예: 남편, 아내)을 입력한다. 초대코드나 QR을 활용한다. 건너뛰기 가능하다. |  |
| 1.1.2 | 입맛 및 알레르기 설정 | 자신과 동반인의 입맛을 설정한다.  (매운맛, 싫어하는 음식,알레르기 여부) 설정은 마이페이지에서 언제든 수정 가능하다. | 필수 |
| 1.1.3 | 여행 국가 선택 | 지원 국가 중 여행할 국가를 고른다. (단일 선택)  | 필수 |
| 1.2 | 해당 국가(지역) 외식 문화 아티클 | 해당 지역의 외식 문화를 설명하는 읽을거리를 제공한다. | 권장 |
| 1.2.1 | 아티클 목록 | 웨이터 응대, 주문 시점과 방법, 결제 시점과 방법, 팁 문화 등 주제별 목록을 보여준다. | 권장 |
| 1.2.2 | 아티클 상세 | 입장부터 계산까지 순서대로 설명하고, 한국 식당 문화와 다른 점을 비교해 보여준다. | 권장 |
| 1.3 | 꼭 먹어볼 음식과 찜하기 | 여행지 대표 음식을 소개하고 먹어보고 싶은 음식을 저장한다. | 권장 |
| 1.3.1 | 대표 음식 리스트 | 음식 사진, 이름, 한식 비유 한 줄을 만약, 사용자가 못먹는 재료가 있다면 한 문장으로 표시를 한다. 카드 형태로 보여준다. | 권장 |
| 1.3.2 | 음식 찜하기 | 하트를 눌러 찜 목록에 저장한다. 찜한 음식은 3.1.2에서 현지 메뉴판과 연결된다. | 권장  |

## **2\. 위치 기반 음식 추천 받기**

사용자의 위치를 기반으로 음식 및 식당을 추천해준다.

| 2.1 | 위치 기반 음식 추천 | 현 위치를 기반으로 미리 저장된 입맛과 가게의 평점을 고려하여 식당 추천리스트를 보여준다. | 선택 |
| :---- | :---- | :---- | :---- |
| 2.1.1 | 식당 안내 | 추천리스트에서 식당을 탭하면 음식 분야와 메뉴를 간략하게 볼 수 있도록 한다. | 선택 |

## **3\. 메뉴판 촬영 및 한식 해석**

메뉴판의 여러 페이지를 모두 찍으면 하나의 메뉴판으로 재구성하여 스크롤하며 파악하기 쉽게 보여준다. 

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 3.1 | 메뉴판 촬영 및 사진 선택 | 메뉴판 이미지를 여러 장 입력받는다. | 필수 |
| 3.1.1 | 카메라 촬영 | 홈 화면의 큰 촬영 버튼으로 바로 카메라를 연다. 메뉴판이 화면에 들어오도록 가이드 프레임을 보여준다. | 필수 |
| 3.1.2 | 앨범에서 선택 | 미리 찍어둔 메뉴판 사진을 불러온다. | 선택 |
| 3.2 | 인식 실패 복구 | 인식이 실패하거나 불확실할 때 다시 시도할 수 있게 한다. | 필수 |
| 3.2.1 | 재촬영 안내 | 흔들림, 어두운 조명, 반사 등 원인을 쉬운 문장으로 알려주고 재촬영 버튼을 보여준다. | 필수 |
| 3.2.2 | 불확실 항목 표시 | 인식 신뢰도가 낮은 메뉴는 점선 테두리 등으로 구분하고 "정확하지 않을 수 있어요"를 안내한다. | 권장 |
| 4.1 | 한글화 메뉴판 재구성 | 최종적으로 인식한 메뉴판 사진 여러 장을 토대로 앱 안에서 사용자 맞춤 한글화 메뉴판을 만든다. | 필수 |

## **4\. 메뉴판**

메뉴판의 메뉴 이름을 탭하면 음식 사진, 한식 비유 설명, 재료·조리법·맛·식감, 알레르기 정보, 그리고 현지처럼 즐기기 위한 팁까지 알아볼 수 있다. 

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 4.1 | 한글로 재구성된 스크롤 가능한 메뉴판 | 큰 카테고리를 분류(에피타이저,육류,주류등)하고 해석된 메뉴를 하나의 메뉴판으로 나열한다. | 필수 |
| 4.1.1 | 음식 사진 | 해당 음식의 대표 이미지를 보여준다. 실제 제공 음식과 다를 수 있음을 작게 표시한다. | 필수 |
| 4.1.2 | 찜한 음식 표시 | 1.3.2에서 찜한 음식이 메뉴판에 있으면 하트 표시를 붙인다. | 필수 |
| 4.1.3 | 알레르기 경고 표시 | 본인 또는 동반인의 알레르기 항목이 포함되거나 포함 가능성이 있으면 경고 아이콘을 붙인다(5.1 연동). | 필수 |
| 4.1.4 | 원문 및 한국식 해석 \+비슷한 한식 비유 설명 | 메뉴 원문, 한국식 해석, 비슷한 한식으로 비유 할 수 있으면 "우리로 치면 ○○ 같은 음식" 형태로 한 줄 비유를 가장 크게 보여준다.  | 필수 |
| 4.1.5 | 재료(소스 포함)·조리법·맛·식감 | 주요 재료, 조리 방식, 맛과 식감을 짧은 항목으로 정리한다. | 선택 |
| 4.1.6 | 어울리는 음료, 주류 페어링 추천 | 어울리는 와인이나 음료가 메뉴판에 있다면 추천하고, 무알코올 선택지도 함께 보여준다. | 선택 |
| 4.1.7 | 환율 변환  | 현지 가격과 환율을 반영한 원화 기준 가격까지 보여준다. | 필수 |

## **5\. 주문 하기**

주문 화면과 오류 신고, 중장년층을 위한 큰 글씨 설정은 경쟁 앱에도 있는 기본기로, 핵심 흐름을 받쳐주는 수준으로 구현한다.

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 5.1 | 장바구니 | 고른 메뉴를 하나의 장바구니에 담는다. | 필수 |
| 5.1.1 | 환율 변환 \- 총 금액 | 메뉴의 원화 환산 금액의 총합을 보여준다. | 선택 |
| 5.2 | 주문 보여주기 화면 | 고른 메뉴를 주문하는 문장을 직원에게 말할 수 있게 정리하고 번역한다. | 권장 |
| 5.2.1 | 주문 목록 화면 | 카드에서 "주문에 담기"를 누른 메뉴를 현지어 원문과 수량으로 크게 보여주고, 아래에 한국어를 작게 붙인다. | 권장 |
| 5.2.2 | 요청 문장 번역 기능 | "덜 짜게", "치즈 빼주세요" 등 필요한 요청을 한국어로 입력하면 자동으로 현지언어로 해석한다. "저는 ○○ 알레르기가 있어요. 이 음식에 들어가나요?"를 현지어로 크게 띄워 직원에게 보여준다. 설정된 알레르기가 자동으로 채워진다. | 선택 |

## **6\. 미식 가이드**

메뉴별 현지식 먹는 법을 설명한다. 한식과 비교하여 설명이 가능하다면 설명한다.

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 6.1 | 메뉴별 상세 미식 가이드 | 주문을 모두 마친 후 진입하는 메뉴 단위 가이드 화면이다. | 필수 |
| 6.1.1 | 먹는 법 | 현지식 먹는 방법을 한식 경험에 빗대어 설명한다. (예: 남은 파스타 소스를 빵으로 닦아 먹는 것은 닭갈비 양념에 밥을 볶아 먹는 것과 비슷하다.) | 필수 |
| 6.1.2 | 알아두면 좋은 문화 | 해당 메뉴와 관련된 현지 관습을 짧게 소개한다. (예: 이탈리아에서는 식후에 카푸치노보다 에스프레소를 주로 마신다.) | 권장 |

## **7\. 식사 후 평가**

식사를 마친 후 각 메뉴에 대해 평가를 한다.

| ID | 기능 | 상세 설명 | 우선순위 |
| :---- | :---- | :---- | :---- |
| 7.1 | 메뉴별 평점 | 식사를 마친 후 메뉴별로 사용자가 직접 평가를 한다. ('또 먹고 싶어요/한 번이면 충분해요/별로였어요') | 필수 |
| 7.1.1 | 사용자 입맛 업데이트 | 평가 내용을 바탕으로 사용자의 입맛을 업데이트하고, 이를 기반으로 다음 식당에서도 메뉴를 추천하는 데 활용한다.  | 필수 |

## **8\. 설정 (마이페이지)**

| 8.1 | 접근성 | 중장년 사용자의 가독성과 조작 편의를 지원한다. | 선택 |
| :---- | :---- | :---- | :---- |
| 8.1.1 | 큰 글씨 모드 | 온보딩과 설정에서 글씨 크기를 고른다. 카드와 목록이 선택한 크기를 따른다. | 선택 |
| 8.2.1 | 닉네임 수정 | 닉네임을 언제든지 수정할 수 있게 한다. | 선택 |
| 8.2.2 | 입맛 수정 | 알레르기나 호불호 식재료를 다시 설정할 수 있게 한다. | 선택 |
