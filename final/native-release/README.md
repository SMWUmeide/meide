사용자님의 React Native 통합 앱을 새 패키지 이름으로 빌드하고 기존 업로드 키로 서명했어요. 버전 1은 실행 시 종료되었고 버전 2는 일부 아이콘이 표시되지 않아 사용하지 마세요. 버전 3은 이 문제를 수정했어요. 번들 구조, 서명, 앱 ID, 16KB 정렬과 서버 비밀 키의 앱 코드 미포함을 확인했어요. 연결된 Galaxy S21에서 홈의 아이콘과 촬영 버튼, 촬영 화면의 아이콘을 확인했어요. 실제 메뉴판 촬영·분석과 초대 링크, 모든 화면의 원래 디자인 일치는 아직 검증하지 않았어요. Google Play 등록·업로드·심사는 진행하지 않았어요. 패키지 이름의 사용 가능 여부는 2026-11-17 확인 시점의 결과이며 앱을 만들기 전까지 예약되지는 않아요.

메뉴 분석 및 공유 서버 설정은 기존 통합 앱과 같아요. 식사 인원과 팁은 각 기기에서 따로 계산해요. **Android 지도 키는 새 패키지 이름과 서명에 맞게 아직 설정하지 않았으므로 지도는 표시되지 않아요.** 주변 식당 목록은 서버 설정과 테스터 권한에 따라 사용할 수 있어요. Google Play에서 앱 서명을 시작하면 Play 앱 서명 인증서도 지도 키 제한에 등록하고 새 버전을 빌드해야 해요.

업로드 키와 비밀번호는 GitHub에 포함하지 않았어요. 안전하게 보관해야 이후 앱 업데이트에 사용할 수 있어요. 이미 App 브랜치에 있는 다른 통합 버전 및 점검용 빌드는 그대로 보존했어요.
