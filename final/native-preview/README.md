# meide React Native 통합 점검 빌드

[점검용 AAB 다운로드](./meide-native-preview.aab) · [SHA-256](./SHA256SUMS) · [앱 원본 코드](./source/)

팀원 앱의 React Native 화면에 메뉴판 분석, 메뉴 선택·상세, 장바구니, 동반인 공유와 주문 문장을 연결한 별도 점검 버전이에요. `final/source/`에 있는 팀원의 통합 작업과 별개로 보관해요. 원본 기준은 `src` 브랜치 커밋 `fa3cf72`예요.

| 항목 | 값 |
| --- | --- |
| 앱 ID | `app.meide.preview` |
| 버전 / 버전 코드 | 0.1.0 / 1 |
| 최소 / 대상 Android API | 24 / 36 |
| 파일 | `meide-native-preview.aab` (디버그 키 서명) |

**이 파일은 점검용이에요.** 정식 Google Play 제출에는 앱 ID 확정과 업로드 키로 서명한 새 AAB가 필요해요. AAB는 휴대폰에 직접 설치할 수 없어요. 실제 Android 기기에서 촬영과 공유 링크를 여는 동작은 아직 확인하지 않았어요.

메뉴 분석은 기존 meide 서버를 사용해요. 공유 방의 생성·참여·메뉴 조회는 서로 다른 두 테스트 사용자로 확인했어요. 식사 인원과 선택 팁은 현재 각 기기에서 따로 계산해요. 빌드 환경 설정 및 실행 방법은 [앱 원본 안내](./source/README.md)를 참고해 주세요. 인증 정보와 비밀 키는 포함하지 않아요.
