# 6주차 기록

## 사용성 테스트 결과 분석

### 1. 테스트 개요

**테스트 시나리오**

사용자는 이탈리아 로마로 자유여행을 떠나 현지 식당에서 식사하려는 상황이다. 외국어로 작성된 메뉴판을 촬영하고, 번역된 메뉴와 음식 정보를 확인한 뒤 원하는 음식을 선택한다. 이후 주문 문장을 생성하여 직원에게 보여주고 주문을 완료하는 과정을 수행한다.

**테스트 목적**

메뉴판 촬영부터 음식 탐색, 메뉴 선택, 주문 완료까지 이어지는 핵심 사용자 흐름이 직관적이고 원활하게 이루어지는지 확인하고, 각 단계에서 발생하는 사용성 문제를 파악하고자 하였다.

### 2. 테스트 수행 결과

**전체 과업 수행 결과: 성공**

사용자는 메뉴판 촬영부터 음식 정보 확인, 메뉴 선택, 주문 완료까지의 전체 과업을 성공적으로 수행하였다. 다만 일부 기능을 인지하지 못하거나 특정 인터랙션에서 어색함을 느끼는 등 사용성 개선이 필요한 부분이 발견되었다.

### 3. 주요 관찰 결과 및 문제점

| 구분 | 관찰된 사용자 행동 | 발견된 문제점 |
| --- | --- | --- |
| 메뉴판 촬영 | 촬영한 메뉴판 사진을 모아 보고 확대할 수 있는 기능을 발견하지 못하고 다음 단계로 진행함 | 해당 기능이 스크롤해야 보이는 위치에 있어 사용자가 기능의 존재를 인지하기 어려움 |
| 메뉴 카테고리 | 메뉴판에 카테고리가 제공되었으나 이를 확인하지 않고 넘어감 | 카테고리가 사용자의 시선을 충분히 끌지 못해 탐색 과정에서 활용되지 않음 |
| 음식 선택 및 담기 | 음식 상세 화면에서 메뉴를 담는 과정이 다소 어색하게 진행됨 | 메뉴를 담는 과정의 인터랙션이 직관적이지 않음 |
| 담기 버튼 | 메뉴판 화면에서 담기 버튼이 너무 작다는 의견을 제시함 | 버튼의 크기가 작아 시각적 인지 및 조작 편의성이 떨어짐 |
| 주문 과정 | 선택한 메뉴를 바탕으로 주문을 완료함 | 핵심 주문 흐름은 정상적으로 수행됨 |

### 4. 사용성 테스트를 통한 개선 방향

**① 메뉴판 촬영 화면의 기능 가시성 개선**

- **문제점:** 촬영한 사진을 모아 확인하고 확대하는 기능이 스크롤 영역에 배치되어 사용자가 기능을 발견하지 못함.
- **개선 방향:** 주요 기능을 스크롤 없이 한 화면에서 확인할 수 있도록 화면 레이아웃을 재구성하여 기능의 접근성과 가시성을 높인다.

**② 메뉴 카테고리의 시각적 인지성 강화**

- **문제점:** 메뉴 카테고리가 존재하지만 사용자가 이를 확인하지 않고 넘어가 탐색 기능으로 활용되지 못함.
- **개선 방향:** 각 카테고리에 해당하는 메뉴 개수를 숫자 배지(Badge) 형태로 표시하여 시각적 주목도를 높이고, 카테고리별 메뉴 구성을 직관적으로 파악할 수 있도록 개선한다.

**③ 메뉴 담기 인터랙션 및 피드백 강화**

- **문제점:** 음식 상세 화면에서 메뉴를 담는 과정이 다소 어색했으며, 메뉴가 정상적으로 추가되었는지 확인할 수 있는 피드백이 부족함.
- **개선 방향:** 메뉴를 담았을 때 '메뉴가 담겼습니다'와 같은 알림(Toast Message)을 제공하여 사용자의 행동에 대한 즉각적인 피드백을 강화한다.

**④ 메뉴 담기 버튼의 조작 편의성 개선**

- **문제점:** 메뉴판 화면의 담기 버튼이 작아 사용자가 불편함을 느낌.
- **개선 방향:** 버튼의 크기와 터치 영역을 확대하고 시각적 강조를 통해 사용자가 버튼을 쉽게 인지하고 선택할 수 있도록 개선한다.

---

### 5. 핵심 인사이트

**Insight 01. 기능의 존재보다 중요한 것은 사용자가 기능을 발견할 수 있는가이다.**

메뉴판 사진 확인 및 확대 기능과 카테고리 기능이 제공되었음에도 사용자는 이를 인지하거나 활용하지 않았다. 이를 통해 기능의 제공 여부뿐만 아니라 사용자의 시선과 탐색 흐름을 고려한 직관적인 UI 배치가 중요함을 확인하였다.

**Insight 02. 사용자의 행동에 대한 명확한 피드백이 필요하다.**

메뉴를 선택하고 담는 과정에서 인터랙션이 다소 어색하게 나타났다. 따라서 사용자의 행동에 대한 즉각적인 시각적 피드백을 제공하여 현재 진행 상태와 행동 결과를 명확하게 전달할 필요가 있다.

**Insight 03. 주요 기능의 시각적 강조와 조작 편의성이 중요하다.**

메뉴 담기 버튼의 작은 크기와 카테고리의 낮은 주목도는 사용자의 원활한 탐색과 조작을 방해할 수 있다. 주요 인터랙션 요소의 크기, 배치, 시각적 위계를 개선하여 사용자가 필요한 기능을 쉽게 발견하고 사용할 수 있도록 해야 한다.

### 6. 종합 결과

이번 사용성 테스트에서는 **메뉴판 촬영부터 음식 탐색, 메뉴 선택, 주문 완료까지의 핵심 사용자 흐름이 정상적으로 작동함을 확인하였다.**

그러나 일부 기능이 사용자의 시야에서 벗어나거나 시각적으로 충분히 강조되지 않아 활용되지 않는 문제가 발견되었다. 또한 메뉴 담기 과정에서 인터랙션의 직관성과 피드백이 부족한 부분을 확인하였다.

이에 따라 **주요 기능의 가시성 확보, 메뉴 탐색 요소의 시각적 강조, 버튼의 조작 편의성 개선, 행동에 대한 즉각적인 피드백 제공**을 중심으로 프로토타입을 개선하고자 한다.

이를 통해 사용자가 별도의 학습이나 설명 없이도 앱의 기능을 자연스럽게 발견하고, 메뉴 탐색부터 주문까지 더욱 직관적이고 편리하게 이용할 수 있도록 하는 것을 목표로 한다.
