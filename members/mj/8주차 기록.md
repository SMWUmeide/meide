- 전체 기능 구조와 화면별 새로운 디자인 프로토타입 제작

- 실제 API 연동이 필요한 부분과 디자인 시연으로 확인할 부분 구분

## 3. 주요 화면 개선

### 홈과 여행지 설정

홈에 촬영, 최근 메뉴판, 미평가 메뉴, 주변 식당 탐색, 한식·아시안 식당 추천, 한국인 입맛 랭킹을 배치하였다. 처음 들어왔을 때 주요 기능을 파악할 수 있도록 간격과 카드 크기를 조정하였다.

위치 표시는 국가와 도시를 함께 보여주는 흰색 캡슐로 정리하고, 공유 인원은 겹친 원형 아바타로 표현하였다. 하단 탭은 반투명 글래스 형태로 다듬었다

식당 확인은 지도 위로 정보 패널이 올라오는 방식으로 정리하였다. 식당명을 제목으로 사용하고, 중복 이름·주소·안내 문구를 줄였다. 예시 분위기 사진 대신 해당 식당의 구글맵 대표 사진을 적용하였다.

### 메뉴판과 한국식 해석

메뉴판은 공식 웹메뉴의 수프·메인 요리·칵테일을 사용하여 구성하였다. 카테고리는 테두리 있는 버튼 대신 텍스트와 선택 항목의 밑줄로 단순화하였다.

메뉴 상세에서는 다음 정보를 구분하였다.

- 한국 음식에 빗대어 맛과 식감을 설명하는 한국식 해석
- 식당 웹메뉴에서 실제 확인한 설명과 재료
- AI가 보충하거나 추정한 일반적인 음식 특성

버섯과 가지를 먹지 못하는 사용자 설정을 메뉴에 반영하고, 동반인의 선택은 일시적인 알림과 지속되는 선택자·수량 표시로 전달하였다.

### 장바구니·주문·마주보기 대화

장바구니는 사람별 주문을 구분하되 불필요한 여백과 가격 강조를 줄였다. 메뉴 목록은 스크롤하고, 합계와 주문 버튼은 하단에 고정하였다. 팁은 선택한 경우에만 계산에 반영하도록 구성하였다.

주문 화면에는 한국어 뜻과 현지어 문장, 음성 재생, 확대 기능을 배치하였다. 요청사항은 단순한 직역보다 현지에서 자연스럽게 쓰는 표현으로 전달하는 방향을 고려하였다.

마주보기 대화는 상하 분할과 직원 영역의 180도 회전을 적용하였다. 각자의 방향에서 본인 발화는 오른쪽, 상대 발화는 왼쪽에 배치하고, 최신 문장과 이전 대화를 크기·굵기·색으로 구분하였다. 발화 중인 영역에만 그라데이션을 적용하고, 중앙에 대화 종료 버튼을 배치하였다.

### 영수증·평가·랭킹

대화 종료 후 영수증 요약으로 이어지도록 연결하였다. 주문 금액뿐 아니라 코페르토, 물·빵 요금, 팁 등 현지 결제 문화를 함께 확인하고, 확인한 추가 요금을 합계에 반영하도록 구성하였다.

랭킹에는 사진과 음식명 외에 별점, 리뷰 수, 한 줄 평을 추가하였다. 현재 평점과 리뷰는 시연 데이터이며, 실제 사용자 평가 수집과 집계는 이후 연동 과제로 남겨두었다.

## 4. API에 대한 고민

서비스를 실제로 구현하려면 하나의 번역 API만으로는 충분하지 않다는 점을 정리하였다. 메뉴판 인식, 음식 설명, 식당 정보, 번역·음성, 공동 장바구니, 환율처럼 역할이 다른 기능을 나누어 검토할 필요가 있다.

| 영역       | 검토할 문제                                                       |
| -------- | ------------------------------------------------------------ |
| 메뉴판 인식   | 여러 장의 사진에서 메뉴명·가격·카테고리를 정확하게 추출하고 중복을 처리하는 방법                |
| 한국식 해석   | 원문의 의미를 유지하면서 한국인이 익숙한 음식과 비교하고, 확인되지 않은 내용을 사실처럼 설명하지 않는 방법 |
| 식당 확인    | 메뉴판에서 찾은 식당명과 위치 기반 후보를 연결하고, 사용자가 직접 수정할 수 있게 하는 방법         |
| 번역·음성    | 자연스러운 요청 표현, 양방향 번역, 발화 감지와 응답 지연을 함께 고려하는 방법                |
| 동반인 공유   | 동시에 메뉴를 담거나 수량을 변경할 때 선택자와 수량을 일관되게 동기화하는 방법                 |
| 환율·추가 요금 | 환율 갱신 시점과 팁·서비스료·자리 비용의 적용 여부를 구분하는 방법                       |

이번 디자인 버전에서는 도시 검색을 실제로 구현하였지만, OCR·범용 AI 번역·실시간 통역·서버 기반 공동 장바구니·실시간 환율은 연결하지 않았다. 이전의 API 검증 결과와 이번 화면 시연의 범위를 구분하여, 이후 실제 연동을 진행할 기준을 마련하였다.

다음 단계에서는 정리한 화면 흐름을 바탕으로 API를 단계적으로 연결하고, 실제 기기와 마주보기 상황에서 가독성·반응 속도·대화 전환을 사용성 테스트로 확인하고자 한다.
