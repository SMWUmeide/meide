# meide Google Play 출시 준비 현황

2026년 11월 19일 기준으로 Android 앱 `com.meide.travelguide`의 Play Console 설정 11개 중 6개를 완료했어요. 주변 식당 검색의 심사 접근 기능은 구현했고, 운영 서버 배포와 새 Android 빌드가 남아 있어요.

## Play Console

- 광고, 정부 앱, 금융 기능, 건강, 콘텐츠 등급, 앱 카테고리·연락처를 저장했어요. 카테고리는 **여행 및 지역정보**이고, 한국 콘텐츠 등급은 **3세 이상**으로 표시됐어요.
- 앱 이름 `meide`, 한국어 설명, 메뉴판 촬영 일러스트를 사용한 스토어 그래픽을 초안에 저장했어요. 팀에서 직접 넣은 `Frame 1.png`가 앱 아이콘으로 표시돼요. 휴대전화 스크린샷은 최소 2장이 더 필요해요.
- 데이터 보안의 사용자 데이터 수집, 암호화 전송, 자동 생성 프로필과 공유 주문용 익명 계정 항목을 초안에 저장했어요. 공개 개인정보처리방침과 계정 삭제 링크를 준비하고, 실제 데이터 처리 방식과 보관·삭제 절차를 확인한 뒤 신고를 마쳐야 해요.
- 대상 연령은 아직 설정 전이에요. 미성년자 이용 제한을 켜지 않는 방향으로 진행해요. Play Console의 심사용 앱 접근 정보를 먼저 완료한 뒤, 앱의 설계 대상에 맞는 연령군과 이용 제한 설정을 확인해요. 콘텐츠 등급은 이 설정과 별개예요.

## 심사 기능과 배포

- 별도 로그인 없이 운영 메뉴판 분석 서버에 테스트 이미지를 보내 마르게리타 피자와 마리나라 피자의 한국어 결과를 확인했어요.
- Android 앱에서 심사 코드를 입력하면 피렌체 예시 위치의 실제 Google Places 검색 결과를 볼 수 있도록 구현했어요. 이 흐름은 별도의 테스트 참가자 등록이나 기기 위치 권한 없이 사용할 수 있어요. [심사 접근 코드](https://github.com/SMWUmeide/meide/commit/59fd5d4)
- Android 앱 코드 내보내기, 모바일 자동 테스트 88개, 웹 자동 테스트 153개, 빌드·린트·디자인 검사를 통과했어요. 운영 서버에 심사 코드를 적용한 뒤 새 서명 빌드에서 실제 검색을 확인해야 해요.
- Google Cloud의 `gmp-demo-project-490285417`에서 팀 공용 개발 계정은 Cloud Run 서비스 목록을 열 권한이 없었어요. 기존 운영 점검 스크립트에 지정된 팀원 계정의 현재 배포 권한을 확인해야 해요. [Cloud Run 서비스](https://console.cloud.google.com/run/services?project=gmp-demo-project-490285417)
- Expo 로그인은 팀에서 완료했다고 확인했어요. `meide2026/minju`에서 Android 출시용 빌드를 만들 권한과 새 서명 빌드는 확인 전이에요. [Expo 프로젝트](https://expo.dev/accounts/meide2026/projects/minju)

## 이어서 할 일

1. 팀원이 `meide-api`를 배포할 수 있는지 확인해요. 권한이 확인되면 서버에 심사 접근을 적용하고 새 Android 빌드를 만들어요.
2. 새 빌드에서 메뉴판 분석과 심사 코드로 주변 식당 검색을 확인해요. Play Console에 영어 안내와 심사 코드를 등록하고 대상 연령 설정을 완료해요.
3. Android 휴대전화 스크린샷을 올려요. 개인정보처리방침과 계정 삭제 요청 경로를 공개하고 데이터 보안 신고를 마쳐요.
