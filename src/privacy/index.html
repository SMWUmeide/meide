meide 개인정보처리방침

시행일 2026년 11월 21일

Meide는 여행 중 외국어 메뉴판을 이해하고, 주변 식당을 찾고, 동반인과 메뉴를 고르는 앱 meide를 운영해요.

어떤 정보를 왜 처리하나요?

프로필과 동반인
앱을 시작하면 기기에 무작위 프로필 ID와 소유 확인용 정보를 만들어요. 입력한 이름, 프로필 ID, 소유 확인 정보는 동반인 연결이나 서버 기능 이용 시 요청을 확인하는 데 써요. 동반인 서버에는 이름, 프로필 ID, 소유 토큰의 해시, 초대 코드, 연결 관계가 저장돼요. 초대 코드나 링크를 받은 사람은 초대한 사람의 표시 이름을 볼 수 있고, 초대를 수락하면 양쪽 동반인 목록에 이름이 표시돼요.
카메라와 사진
카메라는 메뉴판 촬영, 동반인 사진 촬영, 초대 QR 읽기에 사용해요. 사진 선택기를 쓰면 사용자가 고른 사진에 접근해요. 분석에 동의하고 요청한 메뉴 사진은 메뉴 글자 인식, 번역과 구조화에 사용해요. 식당 확인 과정에서는 메뉴에서 읽은 식당명과 식당 식별자를 사용해요. 동반인 표시용으로 설정한 사진은 기기에 저장돼요.
주변 식당과 여행지 검색
위치 권한을 허용하고 주변 식당 검색을 요청하면 당시의 위도·경도를 받아 가까운 식당과 거리를 계산하고 지도에 표시해요. 앱은 이 기능을 사용할 때 위치에 접근해요. 여행지 검색어는 도시와 지역을 찾기 위해 서버에서 처리해요. 지도와 검색의 접속 정보는 서비스 제공과 요청 제한에 사용될 수 있어요.
공유 장바구니
공유 장바구니를 만들거나 참여할 때 별도 로그인 입력 없이 공유용 익명 계정이 만들어져요. 공유 방 ID, 참여자 이름과 익명 계정 ID, 분석한 메뉴, 메뉴 선택과 수량을 저장해 참여자에게 동기화해요. 공유 방에 참여한 사람에게 메뉴와 장바구니 내역, 참여자 이름이 표시돼요.
기기 설정과 운영 기록
선택한 음식 알레르기, 못 먹는 음식, 동반인 표시 사진과 온보딩 진행 상태는 기기에 저장해요. 서버는 서비스 이용 제한과 오류 대응을 위해 접속 IP, 요청 시각·결과, 기능별 요청 건수와 일부 기능의 프로필 ID·요청 ID 같은 운영 정보를 처리할 수 있어요. 이메일로 문의하면 회신 주소와 문의 내용을 확인해 답변과 요청 처리에 사용해요.

어디에서 정보를 처리하나요?

  • Google은 Cloud Run·Firestore로 앱 서버와 동반인 정보를 처리하고, Vision·Cloud Translation·Gemini로 요청한 메뉴 사진이나 인식한 글자를 처리해요. Google Places·Maps에는 주변 검색 좌표, 식당명이나 식당 식별자, 지도 요청에 필요한 정보가 전달돼요.
  • Vercel은 일부 메뉴판 분석 서버와 이 방침 페이지를 호스팅해요. 분석 요청 시 전송한 메뉴 사진과 요청 정보가 이 서버를 거쳐 Google Gemini로 전달될 수 있어요.
  • Supabase는 익명 인증과 공유 장바구니를 제공해요. 익명 계정 식별자, 인증 세션, 공유 방·참여자·장바구니 정보를 처리해요.

동반인 서버의 Cloud Run과 공유 장바구니 데이터베이스는 대한민국 서울 리전을 사용해요. Google과 Vercel의 글로벌 서비스는 기능 요청을 받을 때 위에 적은 사진, 글자, 위치 또는 접속 정보를 미국 등 해당 서비스가 운영되는 국가에서 처리할 수 있어요.

서비스 제공업체의 정보 처리에 대해 문의하려면 아래 개인정보 문의처로 연락해 주세요. 메뉴 사진 전송이나 위치 제공을 선택하지 않으면 해당 사진 분석이나 위치 기반 검색을 사용할 수 없어요.

얼마 동안 보관하나요?

  • 기기에 저장한 설정과 동반인 사진은 변경·삭제하거나 Android 설정에서 앱 데이터를 지울 때까지 남아요. 메뉴 사진과 분석 결과는 앱의 사용 세션이나 캐시에 남을 수 있어요. meide의 메뉴 분석 서버는 원본 사진과 결과를 별도 파일이나 데이터베이스로 저장하지 않아요. 외부 분석 서비스 및 호스팅 업체의 처리 기록에는 각 서비스의 보관 기준이 적용돼요.
  • 서버 프로필과 동반인 연결 정보는 동반인 기능을 제공하는 동안 유지돼요. 연결 해제 시 동반인 관계가 삭제되고, 계정과 관련 데이터 삭제는 아래 방법으로 요청할 수 있어요.
  • 공유 방은 만들어진 뒤 24시간이 지나면 앱에서 접근할 수 없어요. 접근이 만료된 후에도 공유 방 기록과 익명 계정은 서버에 남을 수 있으며, 삭제를 요청할 수 있어요.
  • 접속·오류·사용량 기록과 문의 내역은 오류 대응, 사용량 관리, 요청 처리를 위해 필요한 기간 동안 보관해요. 처리 목적이 끝난 정보는 삭제해요. 법령에 따라 보관 의무가 있는 경우 해당 기간 후 삭제해요.

어떻게 보호하나요?

앱과 운영 서버 사이의 데이터는 HTTPS로 전송해요. 동반인 소유 인증 토큰은 서버에 해시로 저장하고, 공유 장바구니는 참여한 계정만 조회할 수 있도록 접근을 제한해요. 동반인 데이터베이스는 인증된 운영 서버를 통해서만 접근할 수 있도록 설정해요.

계정 및 데이터 삭제 요청

앱을 설치하지 않아도 Meide에 이메일로 계정 및 데이터 삭제를 요청할 수 있어요. 메일에 앱에서 사용한 이름과 삭제하려는 범위를 적어 주세요. 앱에서 요청하는 경우 확인에 필요한 식별자가 메일 초안에 포함될 수 있어요. 비밀번호, 인증 토큰, 신분증 사진은 보내지 마세요.

계정 및 데이터 삭제 요청 이메일 보내기

요청이 접수되면 운영팀이 본인과 대상 데이터를 확인한 뒤 서버 프로필, 초대·동반인 연결, 공유용 익명 계정과 해당 계정에 연결된 공유 주문 정보를 삭제하고 처리 결과를 회신해요. 법령상 보관 의무가 있는 정보는 해당 근거와 보관 기간을 안내해요.

Android의 앱 정보에서 저장공간의 앱 데이터를 지우면 기기에 저장된 설정과 앱 세션이 초기화돼요. 서버 정보 삭제가 필요하면 위 이메일로 요청해 주세요. 이미 외부 메신저로 보낸 초대 메시지나 원본 갤러리 사진은 각각 해당 앱에서 관리할 수 있어요.
