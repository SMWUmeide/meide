# U²-Net small model

`u2netp.onnx` is the U²-Net 4.7 MB salient-object model, converted and distributed by rembg:
https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx

Original model/code: https://github.com/xuebinqin/U-2-Net (Apache-2.0; see U2NET-LICENSE).
Upstream rembg checksum: MD5 `8e83ca70e441ab06c318d82300c84806`.

Inference runs on our server CPU. No paid segmentation API or key is used. Hosting/storage quotas still apply. This is general foreground segmentation, not a guarantee that only a plate is retained. Drinks retain a glass/bottle. Originals and source attribution are preserved. New processing is capped at 20/minute and 200/day through the shared database budget.
