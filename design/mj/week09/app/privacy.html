개인정보와 데이터 처리

메뉴판 촬영 기능의 데이터 처리 안내입니다. 2026년 10월 27일 기준.

메뉴판 사진과 AI

해석하기를 누르면 선택한 메뉴판 사진이 한입 서버를 거쳐 Google Gemini API로 전송됩니다. 사진 원본과 해석한 메뉴는 한입 데이터베이스에 저장하지 않습니다. 현재 탭의 메모리에 남으며 새로고침하거나 탭을 닫으면 사라집니다. Google의 처리는 Gemini API 약관과 해당 프로젝트의 설정을 따릅니다.

웹 메뉴와 음식 정보 검색

식당을 확인하면 식당의 공식 사이트 주소와 촬영한 음식 이름을 Gemini의 URL Context 및 Google 검색 기능으로 조회합니다. 웹 메뉴를 찾지 못하면 일반 음식 정보를 검색하며, 확인한 출처를 표시합니다. 사진에 있는 가격과 판매 상태는 웹 정보로 덮어쓰지 않습니다.

지도와 식당 검색

식당 이름, 그리고 사용자가 위치 검색을 허용한 경우 현재 위치를 Google Maps Platform으로 전송해 식당 후보를 조회합니다. 지도 이동 후 해당 영역 검색을 누르면 지도 중심 좌표로 조회합니다. Google 개인정보처리방침이 적용됩니다.

기기 내 저장과 사용량

여행지·입맛 설정과 기존 프로토타입의 장바구니·평가는 이 브라우저의 로컬 저장소에 저장됩니다. 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 요청 제한을 위해 IP 주소를 단방향 해시한 식별자와 날짜별 요청 횟수를 서버에 기록하며 원본 IP나 사진을 이 기록에 넣지 않습니다.

카메라와 위치 권한은 브라우저 사이트 설정에서 철회할 수 있습니다.
