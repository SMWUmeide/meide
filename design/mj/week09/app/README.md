# 9주차 실행 스냅샷

이 폴더에서 `python3 -m http.server 5181`을 실행하고 http://127.0.0.1:5181/#home 을 연다. 메뉴판은 #menu, 장바구니는 #cart이다. 메뉴를 담으면 기존 기능으로 장바구니를 채울 수 있다. 화면 검수용 시연 메뉴/환율/평점이 포함돼 있으며 실제 식당 주문·결제 완료 기능이 아니다. 외부 API는 기존 공개 서버를 가리키며 키를 포함하지 않는다. 배포 전 API 상태와 비용·할당량은 별도 검증한다.

스타일 순서: receipt-peach-v83.css → design-tokens.css → design-system-week09.css. API와 계산 JS는 이번 디자인 적용 전후 동일하다. 과거 화면별 CSS 복사본은 제출에서 제외했다.
