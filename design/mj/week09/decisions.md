# 원자료에서 규칙으로 정리한 결정

## 조사

raw-value-inventory.json은 기존 style.css의 **선언 문자열**을 색·타입·간격·반경·그림자별로 추출한 원자료다. 과거 덮어쓰기까지 포함하므로 실제 사용 토큰 수로 해석하지 않는다. 값을 합치거나 이름을 붙이기 전의 값/횟수를 보존했다. 실제 적용값은 before-dom-audit.json 및 같은 크기의 3개 캡처로 별도 확인했다.

## 채택·통합·추가

| 종류 | 기존 사례 | 결정 | 근거 |
|---|---|---|---|
| Color | 검정 여러 값, #92939A/#888/#999B9F 보조 글자 | 주 글자 #000, 보조 #55545E | 기존 검정 선호 유지·핑크 끝색에서도 4.647:1 |
| Color | 피치/핑크 그라데이션 | #FFDED5 → #F7BDCA 유지 | 사용자 최종 홈 색감 |
| Color | 눌림·disabled 정의 분산 | primary-pressed/disabled 추가 | 상호작용 상태 명시 |
| Type | 10/11/13/15/17/22/24 등 | 12/14/16/18/26 다섯 단계 | 원문·환산 가독성과 위계 |
| Space | 19,13.5 등 | 4/8/12/16/20/24 | 좌우20·카드16·열12의 4px 격자 |
| Rounded | 여러 반경 | 12/16/24 | 사진/작은 액션/큰 카드 |
| Shadow | 중복·과거 그림자 | card/floating 2종 | 표면·고정 액션의 역할 분리 |
| 예외 | 홈 카메라177×120/반경51 | 컴포넌트 레시피 유지 | 사용자 편집 브랜드 형태 |
| 예외 | 노란 별·주황 못먹는 재료 | 색 유지, 배지 글자 검정 | 기존 흰 글자2.645:1 → 검정7.939:1 |
| 제외 | 블루 동반자 구분 | 중립 면 + 이름 유지 | 사용자 블루 제외 요청 |

이 결정은 사용자 요청을 반영해 Codex와 정리한 적용안이다. 별도의 팀 회의나 투표가 있었다고 기록하지 않는다. 채택 후 25개 Semantic 이름을 부여했고 Primitive를 먼저 만든 다음 Light/Dark 참조를 연결했다. 총 변수55개와 기초 의미토큰25개를 구분한다.
